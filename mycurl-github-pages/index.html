01 / FEATURES

主要功能

01

HTTP / HTTPS

使用標準函式庫建立連線，預設驗證 HTTPS 憑證。

02

多種請求方法

預設 GET；可用 -X 指定 POST、PUT 等方法。

03

標頭與認證

使用 -H 自訂 Header，-u 產生 Basic Auth 標頭。

04

送出資料

-d 傳送表單文字，--data-binary 傳送檔案或 stdin。

05

回應與下載

-I 查看標頭，-i 同時顯示標頭，-o 將內容寫入檔案。

06

控制與回饋

-L 追蹤重新導向，--max-time 設定逾時，--progress 顯示進度。

02 / HOW IT WORKS

一筆請求如何完成？

程式會先解析命令列選項，再送出 HTTP 請求，最後依照選項顯示或儲存回應。

STEP 01解析輸入

讀取 URL、方法、標頭、資料與輸出設定。

STEP 02建立請求

將輸入整理成 HTTP Request；HTTPS 進行 TLS 驗證。

STEP 03取得回應

讀取狀態碼、回應標頭與本文，處理逾時及轉址。

STEP 04輸出結果

輸出到終端機或檔案，並依需求更新下載進度。

03 / QUICK START

執行範例

取得網頁python mycurl.py https://example.com
查看回應標頭python mycurl.py -I https://example.com
追蹤重新導向python mycurl.py -L https://example.com
傳送 POST 資料python mycurl.py -d 'name=Alice' https://example.com/form
下載到檔案python mycurl.py -o page.html --progress https://example.com
執行本機測試python -m unittest discover -s tests -v

執行範例中的 POST 網址僅為示意；實際使用時須換成接受 POST 的 API。
