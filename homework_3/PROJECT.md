## 一、問題與動機
學生可能記得所有作業期限，卻低估完成作業所需的時間。因此，本專案不只記錄待辦事項，也將工作量分配到每天，及早顯示時間不足的情況。

## 二、目標使用者與價值
目標使用者是有多門課程作業與考試複習需求的學生。使用者輸入期限、剩餘時數和每日空閒時間後，即可取得每日工作安排，減少規劃成本並提早調整進度。

## 三、技術與實作
使用 Python 標準函式庫，採最早期限優先的貪婪排程。JSON 保存作業資料，CSV 提供試算表匯出。資料儲存先寫入暫存檔再替換正式檔案，減少寫入中斷造成資料不完整的風險。輸入檢查避免空白名稱、錯誤日期與不合理工時。

## 四、展示流程（約三分鐘）
1. 執行 `py main.py --demo`，說明自動排程和缺少 60 分鐘的提醒。
2. 執行互動程式，新增自己的兩項作業。
3. 設定每日時間，產生七天排程。
4. 記錄已完成工時，重新產生排程，比較結果。
5. 匯出 CSV 並開啟，展示成果。
6. 關閉再開啟，證明資料能保存。

## 五、驗證
提供自動化測試及開發環境實際執行紀錄。Windows 圖形介面與使用者本機執行尚未驗證；繳交前請自行依 README 操作並截圖。不能把預期結果當成自己的實測紀錄。
