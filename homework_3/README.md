# Study Planner｜作業期限與讀書排程助手

## 啟動方式（Windows／CMD／VS Code 終端機）

需要已安裝 Python 3.9 或以上，不需要 pip 安裝任何套件。先解壓縮，再於 main.py 所在資料夾開啟終端機。

```bat
py main.py --demo
py main.py
```

第一行立即展示示範結果，不會變更個人資料；第二行開啟互動選單。macOS／Linux 可將 `py` 換成 `python3`。

## 功能

- 新增、檢視、刪除作業與修改期限。
- 記錄已完成時數，更新剩餘工作量。
- 設定每日可用時數。
- 自動產生 1～366 天的每日排程。
- 顯示逾期、期限前時間不足，以及超出排程範圍的任務。
- 將資料儲存為 JSON，重新啟動後保留。
- 匯出含提醒資訊的 UTF-8 BOM CSV，可用 Excel 開啟。

## 實際操作

1. 執行 `py main.py`，選 5，設定每天可用 2 小時。
2. 選 1，輸入作業名稱、截止日期（例如 2026-11-05）與剩餘時數。
3. 重複新增其他作業，選 6，輸入 7 查看未來七天安排。
4. 完成部分工作後選 3，記錄時數，再產生排程。
5. 選 7 匯出 `schedule.csv`。再次匯出會覆蓋這份 CSV。
6. 選 0 結束。個人資料保存在程式旁的 `tasks.json`。

日期請改成使用當天適用的日期；`--demo` 會自動以今天產生範例日期。

## 排程原理與假設

採用最早期限優先（Earliest Deadline First）的貪婪策略：先依截止日期排序，再逐日分配可用分鐘。每項作業可拆到不同天，且所有作業從今天起都能開始，截止日當天也能安排工作。相同截止日期用內部編號固定排序，沒有額外重要性權重。

例如今天有 120 分鐘，而今天到期的作業需要 180 分鐘：安排 120 分鐘，另外提醒缺少 60 分鐘。逾期任務不再自動安排，需修改期限；超出排程範圍的剩餘工作只提示未排完，不直接宣稱時間不足。

演算法時間複雜度為 O(n log n + d × n)，n 是作業數、d 是排程天數。排程只提供建議，不會自動扣除工時，必須由使用者記錄進度。

## 程式結構

- `main.py`：資料驗證、JSON 存取、排程演算法、互動選單與 CSV 匯出。
- `test_planner.py`：自動化測試。
- `demo_output.txt`：開發環境實際執行的示範輸出。
- `test_results.txt`：開發環境自動測試結果。
- `PROJECT.md`：作業報告與展示建議。

## 執行測試

```bat
py -m unittest -v
```

測試涵蓋每日容量、截止日、時間不足、逾期、範圍外任務、完成項目、資料保存、錯誤輸入，以及排程不修改進度。

## 限制

這是離線命令列程式，不需 API Key，也沒有呼叫 AI 模型。AI 用於協助開發，不代表程式本身是 AI Agent。每日可用時間固定，尚未支援週末例外、指定時段、任務依賴或手機推播。截止時間精度為「天」，有明確小時限制時應提早設定截止日。僅供單一程式實例使用，不支援多人同時寫入。
